# OpenDesign Visual Reference

Visual system reference materials from `https://open-design.ai`.

## Canonical Visual Language (`source-system/*`)

`source-system/*` is **RoleCue's canonical visual-language source**:
- [`SOURCE-DESIGN.md`](./source-system/SOURCE-DESIGN.md) — Core design philosophy, construction-studio thesis, layout, surface, and interaction grammar.
- [`SOURCE-TOKENS.md`](./source-system/SOURCE-TOKENS.md) — Raw measured and observed token inventory (colors, typography, elevation, spacing, radii).
- [`SOURCE-PATTERNS.md`](./source-system/SOURCE-PATTERNS.md) — Recurring structural, hero, grid, and composition patterns.
- [`SOURCE-COMPONENTS.md`](./source-system/SOURCE-COMPONENTS.md) — Component appearance, interaction physics, controls, and states.
- [`SOURCE-AUDIT.md`](./source-system/SOURCE-AUDIT.md) — Extraction scope, methodology, and observation metadata.

### Authority & Boundaries:
- **Direct Visual System Adoption:** RoleCue applies this visual grammar directly to its own product without an intermediate adaptation or softening layer.
- **No Content/Branding Transfer:** OpenDesign branding, trademarks, copy, and product semantics are strictly **NOT** copied.
- **Product Contracts:** RoleCue retains its own product contracts, flows, data models, and accessibility standards.
