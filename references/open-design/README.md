# OpenDesign Visual Reference

This directory contains a small, curated set of visual reference assets extracted from the OpenDesign visual study (`https://open-design.ai/`).

## Purpose

These images exist to preserve **visual grammar memory** for RoleCue:
- Editorial, spacious layout cadence with generous whitespace
- Hairline (1px) quiet borders and subtle, diffused ambient elevation
- 2D editorial composition framing instead of heavy 3D rendering
- Soft environmental lighting washes constrained to outer canvas boundaries
- Near-white canvas with high-contrast near-black typography

## Critical Boundary

> [!IMPORTANT]
> **OpenDesign is visual grammar inspiration, NOT branding or product content.**
> - Do NOT copy OpenDesign branding, wordmarks, trademarks, illustrations, or marketing copy.
> - Do NOT treat this directory as a code dependency or website clone.
> - RoleCue's product semantics, features, and user flows derive exclusively from RoleCue requirements and contracts.

## Curated References

1. **`01-hero-editorial-1440.webp`** — Canonical desktop hero composition: centered editorial headline, pill-shaped category tags, balanced dual-CTA arrangement, subtle environmental wash, and 16:9 media staging.
2. **`02-product-stage-1280.webp`** — Product window composition: editorial sidebar with subtle traffic indicators, clean content framing, and internal component hierarchy.
3. **`03-cta-card-elevation.webp`** — Elevated card surface: hairline borders, subtle inset highlight, diffused shadow, and generous inner padding.
4. **`04-editorial-artifact.webp`** — Editorial artifact presentation: construction geometry, annotation framing, and contrast management between dark media and light canvas.
